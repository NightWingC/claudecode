# Tetris

Clon del clásico **Tetris** en canvas HTML5 puro, sin dependencias ni bundler. El título "TETRIS" se muestra sobre el tablero y en la pestaña del navegador.

## Cómo correr

Abre `index.html` en el navegador, o usa un servidor local:

```bash
npx serve .
```

## Controles

| Tecla     | Acción              |
| --------- | ------------------- |
| `←` `→`   | Mover               |
| `↑`       | Rotar               |
| `↓`       | Bajar               |
| `Espacio` | Caída instantánea   |
| `P`       | Pausa               |
| `Enter`   | Reiniciar (game over) |
